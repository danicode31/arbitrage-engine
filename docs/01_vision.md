# Arbitrage Engine Argentina

## Objetivo

Construir una plataforma de análisis cuantitativo para detectar oportunidades de arbitraje en mercados financieros.

## Alcance

- Acciones
- CEDEARs
- Bonos
- Opciones
- Futuros
- Criptomonedas (futuro)

## Objetivos técnicos

- Arquitectura modular
- Código testeado
- Alta escalabilidad
- Múltiples proveedores de datos
